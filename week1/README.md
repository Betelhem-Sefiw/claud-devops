# Week 1 Linux Hands-on Lab

## Tasks Completed and Commands Used

1. **Created the workspace directory:**
   `mkdir -p ~/claud-devops/week1`

2. **Created `notes.txt` and added text:**
   `touch notes.txt`
   `echo "I have added a text" > notes.txt`

3. **Created the `scripts` directory:**
   `mkdir scripts`

4. **Moved `notes.txt` into `scripts/`:**
   `mv notes.txt scripts`

5. **Searched for `notes.txt`:**
   `find . -name "notes.txt"`
   *(Output: `./scripts/notes.txt`)*

6. **Found a running process and identified its PID:**
   Command used: `ps aux`
   - **The PID identified for the bash process was:** `775`
